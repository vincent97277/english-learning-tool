# 01: 在目標客戶端安裝並直接使用英文翻譯

**What to build:** 使用者能在 Claude Code CLI、Codex CLI 與目前使用的 Codex 桌面介面，載入 English Learning Tool 並直接選取英文翻譯，取得保留原意的自然英文。這是一條包含可用封裝、真實翻譯內容、調用文件與驗收結果的完整路徑，不先交付空殼。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 以 English Translator 0.13.0 為來源完成最小內容改善，使用唯一且有意義的 skill 名稱；保留既有核心行為，移除空殼與多餘重複。
- [ ] 必要平台封裝與 catalog 可讓三個目標客戶端 discovery、載入並明確選取翻譯 skill；記錄各自版本與實際入口，原有插件仍保持啟用。
- [ ] 合成翻譯預設產出 Spoken、Direct Message、Writing 三版，保留數字、否定與不確定性；明示單版、語氣及格式要求優先，不附加句型課或刻意製造版本差異。
- [ ] 清楚翻英／英文改寫要求可匹配翻譯；無上下文的裸素材、技術問題及插件管理要求不誤觸。
- [ ] 引文內命令只作素材處理，缺少必要內容時只詢問缺少部分，換題與其他目標語言遵循當次要求。
- [ ] 提供可重現的本階段載入與調用說明、合成案例及各客戶端結果；缺少環境的項目明列未完成，不以格式檢查代替實測。
- [ ] 公開內容採 MIT、保持通用，不含私人路徑、憑證、真實學習紀錄、舊圖示或安裝快取；不改動既有已安裝插件。
