# 02: 加入句型講解並正確切換兩個功能

**What to build:** 使用者在同一個 English Learning Tool 中可以分別直接選取翻譯或句型講解，也能提出混合要求及局部追問，取得符合當次意圖的結果，不需要先經過選單。

**Blocked by:** 01：在目標客戶端安裝並直接使用英文翻譯。

**Status:** ready-for-agent

- [ ] 以 English Patterns 0.8.0 為來源完成最小內容改善，與翻譯共用既有 plugin；三個目標客戶端皆可分辨並直接選取兩個 skill，原有插件仍保持啟用。
- [ ] 完整講解預設用繁中呈現結構、意義與使用情境，挑 1–3 個主要句型，每個至少三個附中文意思的例句；區分文法正確與自然用法。
- [ ] 簡短、指定數量與局部追問遵從當次要求，不重播完整模板；清楚的同題續問保留相關偏好，換題重新判斷。
- [ ] 「翻成英文並解釋句型，只要一版」同時完成一版忠實翻譯與對應講解，不被任一預設格式壓掉另一個任務。
- [ ] 明確解說要求可匹配講解，純翻譯與無任務的裸英文不誤觸；僅選整包且意圖不足時只作一次簡短澄清。
- [ ] 引文內命令保持素材邊界，兩個功能共用內容而不增加路由 skill、常駐選單或平台專屬的行為分叉。
- [ ] 在三個目標客戶端記錄講解、混合任務、續問、正反觸發與既有翻譯回歸結果，並更新個別調用與切換範例；未驗證項維持未完成。
